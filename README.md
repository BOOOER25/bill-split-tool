# 分摊算账

选择消费，按人数或百分比分摊，记录付款并导出总账单、个人账单。所有操作界面均为 H5，Android 和 iOS 共用同一套页面。

- [在线模拟预览](https://boooer25.github.io/bill-split-tool/)：使用明确标识的模拟账单，浏览器直接体验。
- [正式 H5 入口](https://boooer25.github.io/bill-split-tool/dist/)：通过客户端现有账单读取方式对接真实数据；当前暂定的桥接协议尚需客户端实现或替换。

## 功能

- 从所有本地可访问账本的支出中，合并排序后取最近 200 条，勾选需要分摊的消费。
- AA 平分、百分比分摊；百分比合计必须为 100%，支持一键均分比例。
- 在个人名下独立追加分摊，记录按金额收款，勾选单条或全部结清。
- 总账单和个人账单均可导出文字、图片，图片标题和备注可编辑。
- 分摊、历史记录、收款及结清状态保存在当前浏览器本地，不请求业务服务端接口。

正式页和模拟页使用不同存储命名空间；示例账单只供演示。真实账单读取仍需对齐现有客户端方法，网页无法仅凭这个公开地址读取手机 App 的本地数据库。无需新增原生操作页面。

## 本地运行

需要 Node.js：

```sh
node build.cjs
node serve.cjs
```

打开 `http://127.0.0.1:8787/demo/` 预览；`http://127.0.0.1:8787/` 是正式 H5。GitHub Pages 从仓库根目录发布模拟预览，`dist/` 保留正式版本。

## 交互协议

[统一读取说明](docs/分摊算账-读取本地账单接口.md)、[Android](docs/分摊算账-Android交互说明.md)、[iOS](docs/分摊算账-iOS交互说明.md)。

暂定 `getLocalBills({scope:"all",limit:200,type:"expense"})`：所有账本合并后最多 200 条，每条包含所属账本。若现有 H5 已有读取方法，应复用现有方式。两端协议文件是数据及导出交互约定，包含待实现项，不代表需要制作原生页面。
